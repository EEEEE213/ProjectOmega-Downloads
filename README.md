# Project Omega downloads

[Download the Windows installer](https://github.com/EEEEE213/ProjectOmega-Downloads/releases/latest)

Run the setup file, then use **Project Omega (PC)** or **Project Omega (VR)** from the Start menu. No Godot, Git, or source download is required. For VR, connect your headset and start SteamVR first, with SteamVR selected as the OpenXR runtime.

The installer includes the playable game and all 16 converted enemy models and textures. Windows 10/11 64-bit and a Vulkan-capable graphics driver are required. Setup installs per user without administrator access. The build is unsigned; its SHA-256 checksum is provided with each release.

Run a newer setup in the same folder to update. Use Windows Settings > Apps to uninstall. Saved progress and settings remain in your Windows user profile.

This repository hosts playable installers. The development source repository remains private, and the raw extraction is not part of these downloads.
